Overview
--------

ROBIN is a distributionally-robust reinforcement-learning framework for FPGA
timing closure with a calibrated split-conformal sign-off envelope. See the
:doc:`overview` page for a high-level description, or jump straight to
:doc:`quickstart` to load the released 4,900-run archive.
