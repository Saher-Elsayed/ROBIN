# Security Policy

## Supported Versions

The latest release receives security updates. Older releases are unsupported.

## Reporting a Vulnerability

If you discover a security vulnerability in ROBIN, please **do not** open a
public GitHub issue. Instead, email the maintainer at
`selsayed@seas.upenn.edu` with:

- A description of the vulnerability.
- A reproduction case (commands, inputs).
- The version of ROBIN and Python / PyTorch you used.

You should receive a response within 5 business days. Once the vulnerability
is confirmed, a fix and coordinated disclosure timeline will be agreed.
